Moragent by Rugol

AI Agent Studio para Claude Code. Diseñá, aprendé y desplegá proyectos de IA agéntica — guiado paso a paso, sin perderte en la jerga técnica.

Cómo instalar Ver en GitHub

Qué es

El estudio para construir tu propia IA agéntica.

Moragent es el punto de entrada a la IA agéntica sobre Claude Code: un menú guiado que te lleva de la idea al sistema funcionando. No empezás eligiendo un modelo ni escribiendo prompts: describís qué querés resolver y Moragent te arma los agentes, las skills y la memoria. Pensado para que alguien de negocio —no solo un dev— pueda crear, operar y mejorar sus propios agentes.

Qué hace

Todo el ciclo, en un solo menú.

Nuevo proyecto

Describís tu idea en una frase y te recomienda la arquitectura: qué agentes reusar y cuáles crear.

Crear agentes

Agentes especializados con rol, modelo y memoria propia. Sin boilerplate.

Crear skills

Procedimientos reutilizables (/comandos) que tus agentes ejecutan una y otra vez.

Mi infraestructura

Dashboard de todos tus agentes, skills y memorias en un vistazo.

Aprender

Conceptos de IA agéntica (orquestación, contexto, automatización) explicados con analogías.

Verificar calidad

Checklist antes de entregar: propuestas, reportes, dashboards o código.

Cómo se ve

Un menú, no un manual.

Instalación

En marcha en 2 minutos.

Requisitos: Claude Code y Python 3.10+.

bash · macOS / Linux
# 1 · Cloná el repo
git clone https://github.com/EduardoMoraga/moragent.git
cd moragent

# 2 · Instalá la dependencia (MCP)
python3 -m pip install "mcp[cli]"

# 3 · Abrí Claude Code
claude

# 4 · Lanzá el estudio
› /moragent

# Windows: python -m pip install "mcp[cli]"  ·  setx PYTHON_CMD python  ·  claude
