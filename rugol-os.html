Rugol, el orquestador.

Una sala de control local donde tus equipos de agentes Claude hacen el trabajo, desafían tu pensamiento y recuerdan lo que aprendiste — para que decidas con un mejor proceso, no solo con más información.

El proyecto open-source que le dio el nombre y el ADN al estudio Rugol.

Cómo instalar Ver en GitHub

La idea

Las buenas decisiones no son cuestión de más información, sino de un mejor proceso.

No pensás "qué agente creo". Pensás qué querés resolver — tu marca, tu pipeline de ventas, tu asistente. Cada proyecto se arma con su equipo de agentes, una misión escrita y reglas vivas. Los agentes trabajan y te desafían; vos te quedás con la decisión.

El paradigma

Project-first, no agente-suelto.

Cómo funciona

Tres conceptos. Eso es todo.

01

Proyecto = departamento

Nombre, color, una misión escrita (el porqué) y un equipo de 1–5 agentes. Cada uno lee la misión antes de cada tarea — un ancla contra la deriva.

02

Lecciones vivas

Cuando el equipo aprende algo (un sesgo, una regla de negocio), lo agregás como lección. La próxima vez, todos la leen. La memoria del proyecto crece sin perder contexto.

03

Tipo de tarea + abogado del diablo

Heurística (rápido/barato), Pensar (modelo del agente) o Deliberar (opus). En decisiones importantes, una segunda voz cuestiona la respuesta. Vos decidís.

Por qué es distinto

Economía conductual, hecha software.

Diseñado por un economista, no solo por un dev. Tres principios encarnados en la herramienta:

Sistema 1 vs 2

No pensás en modelos

Elegís el esfuerzo de la decisión (rápida, pensada o deliberada); el sistema elige el modelo. (Kahneman)

Ruido

Una segunda perspectiva

Antes de lo importante, el "abogado del diablo" cuestiona. Dos miradas reducen el ruido. (Kahneman/Sunstein)

Sesgos

Lo aprendido queda anclado

Cada proyecto guarda sus lecciones; el equipo las lee siempre. Lo que aprendiste de la mala no se vuelve a perder.

Casos de uso

Equipos de agentes para lo que importa.

Tu marca

Arquitecto de marca + editor + analista. Lecciones tipo "cero hype" se inyectan en cada publicación.

Tu pipeline de ventas

Prospector + calificador + follow-up. Agenda diaria que no suelta ningún seguimiento activo.

Tu asistente personal

Brief de la mañana, triage de bandeja, captura de fin de día. El equipo invisible que ordena tu día.

Educación

Dos agentes generan un mini-juego HTML+JS para aprender un tema jugando. Doble click y a jugar — sin instalar nada.

Instalación

Tu sala de control, local.

Sin requisitos previos: el instalador trae sus propios runtimes (Python vía uv + Node). Una línea y un wizard. Corre 100% local bajo ~/.rugol.

bash
# 1 · Instalá (Mac / Linux)
curl -fsSL https://raw.githubusercontent.com/EduardoMoraga/rugol/main/installer/install.sh | bash

# Windows (PowerShell):
# iwr -useb https://raw.githubusercontent.com/EduardoMoraga/rugol/main/installer/install.ps1 | iex

# 2 · Configurá (auth + modelo · el wizard te guía)
rugol setup

# 3 · Levantá core + dashboard (abre el navegador)
rugol up

# Dashboard en http://localhost:3000
